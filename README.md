# 💌 DELUSIONAL & ORGANIZED — Custom Invite & Letter Studio

A custom digital invite and letter web app with aesthetic themes, inclusive receiver personas, custom photo memories, an interactive envelope preview, and a **$2–$8** Ko-fi price estimator.

## Features
- **Aesthetic Styles:** Clean Minimal, Cute Overload, Soft Aesthetic, 3D Pop, and Retro Pixel.
- **Inclusive Receiver Vibes:** Supports Female / Femme, Male / Masc, Gay / Queer Fab, Tomboy / Soft Masc, and Any Gender / Neutral options.
- **Interactive Envelope & Live Preview:** Customize sender/receiver names, headline, message, seal color, and up to 3 photos.
- **Dynamic $2–$8 Pricing & Ko-fi Flow:** Calculates estimated price based on style, photos, and email delivery, with shareable `?letter=` link generation.
